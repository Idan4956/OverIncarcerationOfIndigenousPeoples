# Beyond the Numbers

A simple educational website about the overincarceration of Indigenous peoples in Canada.

## Use the site

Open `index.html` in a browser. Select **Edit page** to replace the sample text, add images and captions, and save changes in that browser. Select **Download page** to get an updated `index.html` that includes your saved content and can be published as a static website.

This version does not have a shared online editor or server. Browser-saved edits are local to that browser until you download and publish the updated page. Add accurate source details and confirm permission and consent before publishing text, photographs, or personal stories.
